ABOUT THE PROJECT

Air Quality & Pollution Pattern Analysis

This academic project demonstrates how HTML, CSS, JavaScript, and Chart.js can present environmental data in an interactive dashboard. It compares sample air quality values and visualizes pollution patterns to support basic data interpretation.
